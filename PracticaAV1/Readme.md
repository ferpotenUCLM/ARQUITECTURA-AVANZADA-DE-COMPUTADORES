
# Setup

## Project template

Download project template. 

Unzip the content in the development/workspace directory e.g. `~/dev/aac-exercises/`

## Data

Place the file in an accesible route such as `~/data/aac/dataset.csv`.

# Dependencies

Install the following dependencies:

```bash
sudo apt install build-essential git cmake libglm-dev g++-14 gcc-14
```

Configure GCC 14 as main compiler to support C++20 standard:

```bash
sudo update-alternatives --install /usr/bin/gcc gcc /usr/bin/gcc-14 10
sudo update-alternatives --install /usr/bin/g++ g++ /usr/bin/g++-14 10
```

# Building

Configure the debug build (for development):

```bash
cd <project_folder>/
mkdir debug && cd debug
cmake .. -DCMAKE_BUILD_TYPE=Debug
make -j8
```

Configure the release build (for performance evaluation):

```bash
cd <project_folder>/
mkdir release && cd release
cmake .. -DCMAKE_BUILD_TYPE=Release
make -j8
```


# Running

In order to run the executable generated by the project:

```bash
cd <project_folder>/debug/
./computeShared/computeShared ~/data/aac/dataset.csv
```
